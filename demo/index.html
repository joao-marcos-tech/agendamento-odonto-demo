Preciso confirmar o horário?

A recepção manda uma mensagem pelo WhatsApp. Enquanto isso, o horário já fica guardado no seu nome.

E se eu não puder ir?

Use o link que aparece depois de agendar para cancelar. O horário volta a ficar livre para outra pessoa.
